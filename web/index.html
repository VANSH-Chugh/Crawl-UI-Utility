A LITTLE CONTEXT
From links to usable data.
A focused toolkit for public HTML tables.
01 / ADD
Bring your source links
Paste up to ten public government page URLs. Enable linked pages to check up to four additional pages on the same website.
02 / REVIEW
Keep the context
Review original headings and serial numbers, search records, and follow the source page. Merged header and footer cells are preserved; totals stay separate from records.
03 / HAND OVER
Choose your format
Use CSV for the selected table, JSON for all tables from one source, or a PowerPoint with paginated data tables for the selected source.
Know your sources
The crawler checks robots.txt, fetches public pages with a bounded page size, and reports failures per source. Pages that rely on JavaScript, PDFs, CAPTCHA, authentication, or complex pagination need a dedicated adapter. The sample is illustrative and does not represent live government statistics.
PPT exports use editable tables with source headings, alternating rows, and merged total footers. Long tables continue across slides; source totals appear on the final slide for that table.

Know what’s verified.
Evidence for each check. Clear limits on what the extraction can establish.

    
What we can establish
A passed check confirms only the condition it tests, for the extraction and time shown. It does not guarantee the publisher’s accuracy, field meaning, units, or complete website coverage. Missing evidence is labeled Not verified; it is never counted as a pass.
